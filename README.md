## Descripción

Este es un proyecto de carácter educativo y práctico desarrollado con Spring Boot, diseñado específicamente para aprender y dominar el mapeo de relaciones entre entidades (One-to-One, One-to-Many, Many-to-One y Many-to-Many) utilizando Spring Data JPA y Hibernate. Utiliza H2 como base de datos en memoria, lo que permite un entorno de pruebas rápido y sin configuraciones complejas para experimentar con la persistencia de datos y las consultas relacionales.
